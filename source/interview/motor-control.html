Module 03 / motor control

从功率级走到闭环控制

电机控制不是只会设置 PWM。面试中应能从驱动桥、采样与反馈、控制环和保护时序解释一条完整链路，并明确 FOC 与普通调速的层级差异。

  • PWM · Dead Time
  • ADC · Current Sense
  • Encoder · Hall
  • PID · SVPWM

功率级与 PWM

先保证上下桥臂不会直通，再讨论占空比如何影响平均电压和相电流；驱动器、MOSFET 与电机应视作一整条链路。

DEAD TIME

避免上下桥直通

同一桥臂切换时需插入死区。过小可能产生直通电流；过大则造成有效电压损失、电流畸变和低速抖动。

反馈与 PID

闭环需要可靠的目标值、测量值、采样周期与输出限幅。调参前先验证方向、单位、采样和执行器是否正确。

REFERENCE速度或位置目标，带合理的斜坡限制。
SENSOR编码器、霍尔或估算器给出反馈。
PID计算误差并处理限幅、积分饱和。
PWM输出占空比，再观察实际响应。

FOC 控制链路

FOC 不是 PWM 的同义词。完整链路还需要相电流采样、电角度、坐标变换、电流环及 SVPWM。

SENSE

电流与角度

在合适 PWM 时刻采集相电流；电角度来自编码器、霍尔或观测器。错误的零点或相序会直接破坏控制。

  • 检查 ADC 偏置、比例与采样同步。
  • 明确机械角与电角度的换算。
TRANSFORM

Clarke / Park

坐标变换把三相量投影到更适合控制的坐标系，通常让 d/q 电流可分别作为磁链和转矩相关分量讨论。

  • 回答时说明变换依赖正确角度。
  • 不必把公式背成结论，重点说作用。
SVPWM

调制与电流环

电流环输出电压指令，经逆变换与 SVPWM 转为三相占空比；控制周期和限幅要与功率级能力匹配。

  • 区分电流、速度和位置环的带宽。
  • 过流、欠压等保护优先于控制性能。

Debug path

保护与调试顺序

电机不转或抖动，第一步看什么？

先断开复杂算法：确认供电、故障脚、PWM 波形、相序、使能逻辑和传感器方向。不要一开始就盲调 PID 或 FOC 参数。

积分饱和如何处理？

执行器达到占空比或电流限幅后，积分项仍累积会导致恢复慢和严重超调。可用积分限幅、条件积分或反算抗饱和。

Interview drills

高频追问

死区为何不能设置得越大越安全？

死区过大使有效电压下降并带来波形畸变、低速性能变差；需要在直通风险和控制误差之间结合硬件延迟取平衡。

使用六步换相是否等于实现 FOC？

不是。六步换相是一种换相策略；FOC 要有电流采样、坐标变换、角度和电流环等完整闭环链路。
